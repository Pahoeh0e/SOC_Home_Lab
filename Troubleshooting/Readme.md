# Troubleshooting Notes

A collection of real problems I encountered while building my home SOC lab and the exact steps I took to fix them.

## Why This Exists

I believe the best way to learn is to break things, fix them, and write it down.
These notes are for:
- Future me, when I hit the same problem again
- Anyone else building a similar lab
- Recruiters who want to see how I think through a problem

## Lab Environment
- **Hypervisor:** Proxmox
- **Firewall:** pfSense
- **SIEM:** Wazuh
- **Victim VMs:** Ubuntu Server, Windows Server, Windows User
- **Attacker:** Kali Linux
